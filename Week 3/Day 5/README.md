# 🚀 Week 3 - Day 5: PySpark DataFrame Filtering & Column Renaming

## 📌 Objective

Learn and practice DataFrame filtering, column aliasing, column renaming, and data selection operations using PySpark.

## 🛠️ Technologies Used

- Python
- PySpark
- Databricks

## 📚 Concepts Covered

- DataFrame Creation
- Column Selection (`select`)
- Column Aliasing (`alias`)
- Filtering Rows (`filter`)
- Conditional Filtering
- Range Filtering (`between`)
- String Functions
  - `startswith()`
  - `endswith()`
  - `contains()`
- Logical Operators (`&`, `|`)
- Column Removal (`drop`)
- Column Renaming (`withColumnRenamed`)
- Using `col()` Function

- Selected specific columns from DataFrames
- Renamed columns using aliases
- Filtered employees based on salary, age, city, department, and joining date
- Applied AND and OR conditions in filters
- Used `between()` for range-based filtering
- Performed string-based filtering using startswith, endswith, and contains
- Removed unnecessary columns using `drop()`
- Renamed DataFrame columns using `withColumnRenamed()`
- Created customized views of employee data

## 🎯 Key Learnings

- Efficiently selecting and transforming DataFrame columns
- Applying different filtering techniques
- Working with aliases for readable outputs
- Renaming columns permanently in DataFrames
- Using string operations in filtering conditions
- Building clean and reusable PySpark transformations
